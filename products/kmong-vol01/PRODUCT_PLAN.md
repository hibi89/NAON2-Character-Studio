## 실제 제공할 구매자 파일
- **1순위 = 15개 원본 PNG**(원래 파일명/픽셀/비트 품질 보존). 모두 `Original_15/` 등 한 폴더에, `MANIFEST.txt`에 원본별 이미지 픽셀·크기·해시 정리.
- 한 장짜리 한국어 `사용안내_및_이용범위.txt` 또는 PDF: 적용 안내, 개인 감상/배경화면, 구매자에게 허용되는 사용, 재판매/재배포/상업 목적 미포함(상업권/원본 권리 확인 후만 확정), 환불 관련 플랫폼 정책.
- **선택사항**: 특정 이미지가 실제 사용할 스마트폰/PC 화면과 비율이 맞지 않으면 원본을 바꾸지 않고 `Wallpaper_Optimized/`에 **파생본 별도 추가**. 자르더라도 주인공 고양이 귀/발/꼬리 온전하게 보존, 상하 여백/배경 확장 등 우선. 작은 이미지의 단순 확대를 네이티브 고해상도로 홍보하지 않기.
- 중요: `image(20260928-233741).png` 같은 원본은 **208×208px의 저해상도**로 알려져 있다. 15개 중 일부는 픽셀 크기가 작아 모든 15장에 PC 2560×1440 / 모바일 1440×2560을 약속할 수 없다. **모든 15개 원본의 실제 이미지 크기와 사용 적합성 검사 후** 상세 문구를 결정.
- 상품 정보 파일: 이미지 해상도표/사용 설명/선정 15작품의 미리보기. 내부 GitHub 빌드/원본 참고시트/개발코드/QA 경로는 구매자 ZIP에 넣지 않음.

## 크몽에 올릴 홍보 이미지
- **메인 1장**: 정확히 **652×488**, 유색 배경, 50px 안전 여백, 15장 중 품질/시선 집중이 좋은 컷을 포인트로 사용. 할인·가격·외부 연락처·워터마크 금지.
- **상세 이미지 1~9장**: 가로 652~2000px, 세로 3000px 이하. 권장 **6장**: (1) 나온이 캐릭터 소개/세계관, (2~4) 15개 작품 미리보기 5컷씩, (5) 실제 포함 파일·픽셀/적용 예시, (6) 사용권/구매 안내. 모두 **실제 선정작만 사용**. 대표/상세 이미지와 실제 ZIP이 일치하도록.
- 메인/상세 형식 PNG/JPG; 모두 실제 파일 디코딩·픽셀/크롭/폰트/가독성 확인.
- 캐릭터 소개는 일관된 회갈색/흰색 털, 큰 갈색 눈, 복슬하게 말린 꼬리, 분홍 코·귀, 게이머와 우주를 비롯해 새로운 장소를 탐험하는 호기심 많은 고양이, 브랜드 문구 `어디에든 나오는 호기심 많은 고양이` 중심. **이 설정을 실존/독점 저작권 주장으로 연결하지 말 것**.

- Codex 크몽 계정 드라이런: 임시 카테고리 `자료·템플릿 > 취미 자료 > 기타` (최종 적합성 미확정), 최소 판매가 5,000원, ZIP **파일당 200MB 이하**, 제목 **10~30자**, 설명 **100~20,000자**, 사용자 실제 등록 편집 ID **840876** 확인 후 중복 등록 방지.
- 모든 이미지 파일 원본은 GitHub에 15개 **blob 존재 및 각 파일 바이트 수** 확인. 이번 작업에서는 GitHub private 바이너리 fetch 수단이 디코딩 오류를 반환해 모든 15장의 이미지 픽셀 정보를 검증하지 못함. **원본 픽셀/시각 QA는 미완료**로 남김. 어떤 파일도 픽셀 해상도 확인 전 임의 편집/보간/패키징하지 않음.
- 권리·상업적 이용: 최초 입력 이미지 권리·AI 사용 방식, 구매자 개인 사용권/금지 범위, 폰트 파일 미제공, 메타데이터/외부 표장 유사성 확인. 등록 설명에 AI 사용 여부 사실대로 표시.
- 새 홍보 이미지 및 최종 ZIP **아직 제작/최종 QA/사용자 최종 등록 승인 받지 않음**. 기존 `PRE_SUBMISSION_RC`의 12 PNG 러프는 **폐기 대상이 아니라 과거 검수 이력**이며 이번 실제 판매물로 사용하지 않음.
