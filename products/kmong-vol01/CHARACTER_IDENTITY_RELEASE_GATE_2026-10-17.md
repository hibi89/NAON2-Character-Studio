- 러프 제작 코드 `reproduce/build_naon2_only_vol01.py`는 하나의 고정 `naon2-front-candidate-v02-raw.png`를 불러 각 테마 배경에 합성했다. **12장 모두 새로운 캐릭터를 생성한 것이 아니라 동일한 v2 캐릭터 한 개를 크기 조절·크롭·배치한 구조**. 얼굴/색을 테마별 AI 재생성하지 않음.
- **핵심 판정:** 위 사실은 '**12장 모두 v2 한 파일에서 왔다**'는 소스 추적/일관성만 증명. '**v2가 사용자 승인 브랜드 가이드 및 최초 게이머와 완전히 같은 디자인**'이라는 판단은 **증명하지 못함**. 원본 대비 이마 흰색 무늬, 눈 간격·비율, 꼬리 크기·방향, 표정/신체 비례 차이가 기존 QA에서 확인됨. 사용자 최종 디자인 승인은 아직 없음.
- 기술 등급 **PASS** / 정체성 승인 **PENDING** / 실제 판매 파일 **BLOCKED**. 파일명 변경이나 DRAFT 제거로 출시 승인 처리 금지.

## 2. 최종 12장 캐릭터 검사 방식 (통과할 때까지 반복)
각 최종 PNG마다 독립적으로 다음 기준을 확인한다.

| 항목 | 판정 기준 |
| --- | --- |
| ID | 사용자가 지정한 **NAON2**, DAON2·다른 고양이 X |
| 얼굴 | 고유 회갈색 얼굴 마스크/흰 주둥이/이마 무늬, 둥근 눈 비율 및 간격 |
| 신체 | 따뜻한 털색 분포, 흰 가슴, 작은 발, 볼륨 큰 말린 꼬리의 동일성 |
| 구도 | 귀·꼬리·모든 발이 잘림 없이 보이고 모바일 시계/아이콘 영역과 충돌 없는지 |
| 소스 | 어떤 공식 기준 컷에서 나왔는지 ID와 소스 해시를 최종 파일별 기록 |
| 변형 | 배경·조명·소품 변화를 허용하되 본체의 눈/털 무늬/꼬리 디자인이 다른 캐릭터로 바뀌면 FAIL |
| 기술 | 실제 파일이 열리는지, 지정 해상도, 색공간, 문자·워터마크·권리 침해 요소 없음 |
| 최종 승인 | **사용자가 비교판에서 원본과 동일 캐릭터라고 승인**. 자동 유사도나 SHA 단독으로 통과 처리 금지 |

*정확히 같은 정면 스탠딩 이미지의 배경 합성*이면 캐릭터 이미지는 원본과 같은 모양을 **확대/축소 후 합성**할 수 있다. *새 포즈·표정·의상 제작*을 요구한다면 픽셀 동일성은 불가능하므로 캐릭터 외형 정체성의 일치 검수가 필요하며 자동으로 100% 보장하지 않는다.

## 3. 출시 절차 (사용자가 정한 정확한 분업)
**① ChatGPT**: 이미지/파일 원본 일치 현재 상태를 점검하고 러프 구조를 보존한다.

**② Codex — 크몽 실제 등록 화면 전 과정 드라이런**: 로그인·카테고리·형태·썸네일·상세·가격·파일 전달·판매/저작권/정책을 **모두 확인**, 가능한 범위에서 **제출 직전까지** 테스트. `제출/공개/상품 등록 확정` 버튼은 **절대 누르지 않는다**. 필요하다면 비공개 초안 상태에 한해 명시 동의받고 저장한다. 정확한 누락 사항 및 크몽 실제 규격을 보고한다.

**③ ChatGPT**: Codex의 화면 기반 검사 결과/누락 항목을 받아 해결한다. 모든 나오니 캐릭터 컷을 공식 기준에 맞추고, 최종 썸네일·상세·구매자용 12 PNG 및 안내문, 라이선스 자료/최종 ZIP을 생성한다. 다시 QA 후 사용자에게 제출물 미리보기/해시/파일 목록을 준다.

**④ 사용자**: 최종 디자인 동일성, 상품 내용, 가격, 권리 고지, 실제 등록 의사를 명시 승인한다.

**⑤ Codex — 실제 등록**: 최종 ZIP만 전송하고 실제 제출 후 접수 상태/ID/화면을 보고한다. **최종 심사 승인 및 판매 개시는 크몽 별도 결과**다.

## 4. Codex가 보고해야 할 누락 항목 (정확한 증거 첨부)
- 등록 가능한 실제 카테고리 및 판매 상품형태 (기성 디지털 PNG ZIP), 필수 계정 인증/프로필.
- 제목 글자수/금칙 표현/AI 이용 고지 필드, 상품 설명 및 이미지 필드 각각의 요구 규격.
- 대표/추가 이미지 파일 규격·비율·용량·장수, 상세 이미지 규격, 미리보기 파일 요구.
- 고객 최종 파일 전달 방식/용량 제한/첨부 vs 메시지 전달 여부.
- 최소 가격/수수료/옵션 구조, 납기·수정·환불 조건, 상업적 이용/저작권/라이선스 정책.
- 어느 화면 어느 입력란에서 무엇이 빠졌는지 **실제 UI 근거**와 우선순위(출시 차단 vs 선택).
- 현재 폴더의 DRAFT 워터마크/출처 코드/검수용 자료가 섞인 사유와 구매자용 최종 ZIP 분리 조건.
