# PNG 바이너리 업로드 대기

현재 GitHub 연결은 문서 작성이 가능하지만 로컬 PNG 원본을 GitHub API로 전달할 수 없어 아래 파일 3개가 저장소에 아직 없습니다.

- `assets/originals/naon2-gamer-original.png` (96,666 bytes)
- `assets/originals/naon2-astronaut-original.png` (3,681,149 bytes)
- `assets/references/naon2-character-sheet-v1.png` (2,237,668 bytes)

원본 3개는 [NAON2-Character-Studio-initial.zip](sandbox:/mnt/data/NAON2-Character-Studio-initial.zip)의 같은 경로에 보존돼 있습니다. 이 링크는 채팅 작업 공간용으로 영구 외부 URL이 아니므로, 이미지 복원에는 사용자가 해당 ZIP을 보관해야 합니다.

원본별 해시는 `asset-manifest.json` 참고. 이미지를 업로드한 뒤 `python scripts/verify_assets.py`로 일치 여부를 확인하십시오.
