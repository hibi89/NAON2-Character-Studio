# 원본·저작권·이용 조건 확인 메모

- 사용자가 제공한 이미지 2장과 승인한 생성형 AI 가이드 시트 1장을 확보했습니다.
- 실제 생성 도구·원본 라이선스·이용 약관·최종 권리 귀속은 검증 전입니다.
- '오리지널 캐릭터 콘셉트'로 소개할 수 있으나 독점적 저작권·상표 등록·제3자 권리 비침해를 보장하지 않습니다.
- 저작권 보호 범위는 제작 과정과 관할법에 따라 달라질 수 있습니다. 크몽에서는 생성형 AI 사용과 허용 범위를 정확하게 기재합니다.
- API 키·로그인·결제·개인정보는 저장소에 포함하지 않습니다.
- 외부 공개와 판매 전 이용 조건을 추가 검증합니다.
