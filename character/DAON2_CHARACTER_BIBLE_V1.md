## 3. 시각적 정체성 (첫 이미지에서 관찰된 특징)
- 전체 실루엣: 작은 전신, 둥근 머리·큰 눈·포근한 볼과 가슴의 매우 복슬복슬한 털.
- 색: **희고 은회색 계열의 털**, 얼굴/가슴/발의 밝은 부분. 나온이의 따뜻한 회갈색 고양이와 구분.
- 눈: 크고 맑은 **푸른 회색 계열 유광 눈동자**, 또렷한 빛 반사.
- 작은 분홍 코, 분홍빛 귀 안쪽, 짧고 포근한 전지, 뒤에서 휘어진 풍성한 꼬리.
- 표현: 부드러운 **입체/CGI풍 털 질감**, 온화하고 조용한 인상.
- **원본 기준에서 임의로 바꾸면 안 되는 요소**: 눈동자 색/하이라이트, 얼굴 길이와 눈 간격, 은회색 털 분포, 귀 형태, 꼬리 볼륨.
- **추가로 상상하면 안 되는 설정**: 분홍 리본/금색 메달은 원본에 없음; 뒤의 실패한 멀티뷰 실험 소품일 뿐 **공식 기본 착장 아님**.
- 생성 모델이 나온이의 갈색 얼굴 마스크/일러스트 스타일을 다온이에게 덮어씌우지 않도록 캐릭터를 개별 처리한다. 합동 굿즈의 렌더 스타일 통합은 원형 확정 후 별도 검수.

## 6. 시각 표준화 로드맵 및 QA
1. 원본 PNG를 별도 원본 위치에 **바이트 동일 업로드 및 SHA-256 확인**(아직 미완료).
2. 같은 캐릭터의 배경 정리·안전 여백·정면 표준화. 원본과 비교하며 포토리얼/CGI 인상 유지.
3. 이미지 참조 편집이 실제 제공되는지 확인 후 **90° 측면 1장**만 시도. 이미지 패널 크롭이나 임의 콜라주 금지.
4. 형태·털 무늬·눈·꼬리가 정면과 일치하고 귀/꼬리/발이 잘리지 않으면 후면·표정·포즈 확장.
5. 같은 브랜드 시트 레이아웃으로 **DAON2 모델 시트** 구성하되 나온이의 갈색 눈/갈색 털을 가져오지 않는다.
6. 사용자 외형 승인·상업적 이용/생성 도구 조건·파일 QA 후에만 굿즈/크몽 판매 승인 여부 결정.
