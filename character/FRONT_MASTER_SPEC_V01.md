# NAON2 — 공식 정면 마스터 제작 기준서 v1.0

**상태: 제작 기준 확정 / 정면 마스터 원화 자체는 미제작.** 2026-10-16 사용자 피드백 반영: 기존 SVG 벡터 v0.1은 디자인 불합격, 재사용 금지(기술 이력으로만 보존).

## 1. 목표
**다른 귀여운 고양이를 그리지 않는다.** 사용자 원본의 나온이를 그대로 알아볼 수 있는 **정면 전신 1장**을 제작한다. 얼굴의 정체성 유지가 해상도나 화려한 그림체보다 우선한다. 정면 통과 전 측면·후면·크몽 6종 파생 제작을 중지한다.

## 2. 기준 이미지와 적용 순서

| 우선순위 | 파일 | 사용할 요소 |
| --- | --- | --- |
| A (정체성) | `assets/originals/naon2-gamer-original.png` | 얼굴의 느낌, 눈매·눈 크기, 주둥이, 털의 명암과 부드러운 입체감 |
| C (정면 구조) | `assets/references/naon2-character-sheet-v1.png` | **의상 없는 정면 전신**의 자세·몸 비율·회백색 분포·발바닥·꼬리 |
| B (보조) | `assets/originals/naon2-astronaut-original.png` | 캐릭터가 움직여도 유지되는 귀·얼굴·꼬리의 특징 |
| C에서 분리한 참고컷 | `assets/derivatives/reference-isolates-v03/naon2-front-reference-v03.png` | 정면 외곽 비교용. **214×213px 소형 추출 이미지**, 직접 고해상도 원화 아님 |

A는 정면 사진이 아니므로 얼굴 특징은 A를 따르되 정면 구조는 승인된 C의 정면 캐릭터를 우선한다. 조명에 따라 색이 달라 보일 수 있다. 공식 색상 HEX와 비율 숫자는 원본 색상 분석 전까지 임의 확정하지 않는다.

## 3. 변경 금지 — 외형
- 큰 둥근 갈색/검정 계열 눈, 눈 간격, 짧은 주둥이와 작고 분홍빛 코
- 둥글고 통통한 얼굴 윤곽 및 뺨, 얼굴 아래쪽의 흰 털 경계
- 회갈색 윗머리·등과 흰색 가슴·배의 기본 털 배치
- 분홍빛 귀 안쪽, 작고 짧은 발, 통통한 치비 체형
- 풍성하고 위로 말린 꼬리(끝의 따뜻한 갈색 명암 포함)
- 원본의 부드럽고 입체적인 일러스트 질감과 따뜻한 인상

**금지:** 낯선 눈매/비율, 새로운 무늬, 다른 꼬리 형태, 매끈하고 단순한 평면 벡터화, 지나친 실사화, 새 액세서리·의상 추가, 원형보다 예뻐 보이게 한다는 이유로 얼굴 재설계.

## 4. 납품 대상 — 단 1장
- 완전 정면·의상 없음·한 마리·전신(귀·발·꼬리 모두 화면 안).
- 중립적이고 다정한 표정; 눈·코·입이 자연스럽고 좌우에서 동일 캐릭터처럼 보일 것.
- 투명 배경 RGBA PNG, 가능하면 **네이티브 2048×2048 이상**; 단순 보간 업스케일을 신규 고해상도 디테일로 설명하지 않는다.
- 가능하면 수정 가능한 레이어 원본(PSD/KRA 등) 및 편집 이력 보관. 단순 PNG는 레이어 원본이 아니다.
- 개별 결과물만 제공. 홍보 포스터/문자/다중 뷰 합성 이미지 금지.

## 5. 권장 제작 경로 — 2안 비교

| 방법 | 시간/비용 | 원형 보존 기대 | 한계 |
| --- | --- | --- | --- |
| **A. 원본 기반 정밀 편집/부분 재작화** | 중간 / 사용 도구에 따라 다름 | **우선 추천**: 승인 시트의 정면 고양이를 그대로 기준으로 유지 | 소형 원본의 디테일 부족, 전문가 수준의 보정이 필요할 수 있음 |
| B. 레이어형 수작업 재원화 | 높음 / 추가 인력·도구 비용 가능 | 직접 통제·수정 가능성이 가장 큼 | 시간이 오래 걸리고 작가의 해석이 개입할 수 있음 |

같은 이미지 생성 프롬프트를 반복하는 방식이나 기존 벡터의 재사용은 하지 않는다. 외부 편집 서비스에 사용자 원본을 올리는 작업에는 별도 사전 승인이 필요하다.

## 6. 승인 게이트 (하나라도 실패하면 마스터 아님)
1. **캐릭터 동일성:** A와 C를 나란히 봤을 때 사용자가 즉시 나온이라고 인정하는가?
2. **형태·색:** 눈·코·귀·주둥이·털 패턴·꼬리·체형이 유지되는가?
3. **오류:** 팔다리 중복, 꼬리 잘림, 비정상 눈·발, 의도하지 않은 글자·로고가 없는가?
4. **품질·출처:** 원래 해상도·편집 방식·원본 파일·사용권을 실제로 확인했는가?
5. **최종 승인:** **사용자가 정면 결과물 자체를 승인했는가?** 기술 테스트나 자동 검사만으로는 통과시키지 않는다.
