# NAON2 Character Studio — 나온이

> 어디에든 나오는 호기심 많은 고양이, 나온이(NAON2).

NAON2 캐릭터의 일관성, 기준 이미지, 파생 아트, 크몽 디지털 컬렉션 출시 과정을 기록하는 **비공개 프로젝트**입니다.

## 프로젝트 상태 (2026-10-16)

- 사용자 승인: **캐릭터 표준화 시트 v1의 시각적 콘셉트 승인**
- 원본 이미지: 게이머/우주비행사 2장, 원본 파일 보존
- 표준 시트: 단일 평면 이미지(flattened) 1장. 레이어 원본이 아니며 100% 동일 캐릭터의 정밀 모델 시트라고 간주하지 않음
- 표준 원화 정면·측면·후면 개별 재작업 및 동일성 검증: **미완료**
- 크몽 상품 출시 기획: Vol.01, 6종 시안 / 제안가 9,900원 (실제 등록 및 판매 가능성 미검증)
- GitHub: **문서와 검증 코드 업로드 완료 / PNG 3개 미업로드** (자세한 내용은 `STATUS.md` 참고)
- 크몽 등록: **미완료**

## 작업 기본 원칙

1. 게이머 원본을 **얼굴·비율 주 참조**, 우주비행사 원본을 **확장성 보조 참조**, 시트 v1을 **승인된 디자인 가이드**로 사용합니다.
2. 세계관에 따른 의상·배경은 변경할 수 있지만, 눈·얼굴·털 배치·꼬리의 정체성은 유지합니다.
3. 캐릭터가 100% 고정되었다고 가정하지 않고 신규 이미지마다 인물 동일성 검수를 합니다.
4. 원본을 덮어쓰지 않습니다. 기존 버전과 검수 결과를 남깁니다.
5. 생성형 AI 사용 사실을 판매 정보에 정확히 표시하고, 법적 독점권 또는 상업적 권리를 근거 없이 보장하지 않습니다.
6. 비밀 키, 개인정보, 인증 토큰은 저장소에 업로드하지 않습니다.

상세 사항은 `AGENTS.md`, `REQUIREMENTS.md`, `STATUS.md`, `character/CHARACTER_BIBLE.md`를 확인하세요.
